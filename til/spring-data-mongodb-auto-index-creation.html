TIL01 — MongoDB Index Auto Creation & Testcontainers

Filed under: Spring Boot, MongoDB, Testcontainers

Today a simple unit test case expected to throw DuplicateKeyException failed when an item with the same unique value was inserted.

Apparently, when running tests with Testcontainers, you have to explicitly enable the following property so Spring Data MongoDB creates the unique index for your entity/entities: 

spring.data.mongodb.auto-index-creation=true
